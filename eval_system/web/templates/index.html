触发评测

两种使用模式（同一套评测，用途不同）：
模式目的怎么用结果怎么看
选型对比 横向比较多个模型，挑出最合适的 在下方多选模型，一次跑多个 看报告的模型对比矩阵（按平均分排序）
CI 回归门禁 防止某个模型/版本质量退化，卡上线 命令行 python run_ci.py --dataset smoke --threshold 0.7 低于阈值即判失败、返回非零退出码，阻断流水线

简言之：选型对比关心「哪个模型更好」，是相对排名； CI 门禁关心「够不够格上线」，是绝对阈值判定。两者跑的是同一套用例与评分。
